# 🛒 e-Store

A modern **React + Redux** based e-commerce app where users can view products, search by name or category, and add products to the cart.  
The app is built with **Tailwind CSS** for styling and is fully responsive.

---

## 🚀 Features

- 🔍 **Search Products** by name or category (real-time filtering).
- 🖼️ **Responsive Product Cards** with hover animations.
- 🛒 **Add to Cart** functionality.
- 📱 **Mobile-friendly Navbar** with hamburger menu.
- 🎨 Styled with **Tailwind CSS**.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Redux, React Router  
- **Styling:** Tailwind CSS  
- **Icons:** React Icons  
- **State Management:** Redux Toolkit
